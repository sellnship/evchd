⚡ Content Pipelines

How articles are generated & published on evchandigarh.in — the original Engine pipeline (GitHub Actions + cron) vs the new Admin pipeline (admin panel + Neon DB), and which to prefer when verification before posting matters.

🏁 Verdict — ranked by verification before posting

🥇

Admin ▶ Engine (hybrid)

Recommended default

All four automated gates — including the fact-check against the curated data layer — plus human review in the admin editor. Same rigor as the original pipeline, far nicer review surface. Use for anything factual: rules, tariffs, costs, buying guides.

🥈

Engine (cron + PR)

Equal rigor, slower surface

Identical gates; the human gate is a PR merge. Right for the markdown sections and hands-off weekly cadence. Ranks second only because reviewing a markdown diff is clumsier than the rendered admin editor.

🥉

Admin ⚡ Draft with AI

Fastest — human-only verification

Zero automated verification. Fine for opinion pieces, seasonal notes, event round-ups. Not for regulatory/pricing content unless you verify every figure yourself before publishing.

Rule of thumb: if the article contains a number or a rule, run it through a gate (▶ Engine). If it's a story or an opinion, ⚡ Draft is fine — either way, nothing publishes without a human clicking Publish / Merge.

👩‍💻 Operator Guide — using the Admin day-to-day

Written for a NEW operator — no coding needed. The admin runs at its own URL (locally http://localhost:4321; in production the evchd-admin Vercel URL).

1 · Sign in

→
Open the admin URL → enter email + passwordCredentials are set by the site owner (ADMIN_EMAIL / ADMIN_PASSWORD). Session lasts 7 days; use Sign out in the sidebar when done on a shared computer.

2 · Know the sidebar

MenuWhat it's for
▦ DashboardCounts (published / drafts / queued topics) + recent activity feed + shortcuts
✎ Blog CMSAll blog articles — filter by Published/Drafts, open any to edit, create manually
🤖 AI GeneratorThe AI workflow: suggest topics → queue → generate articles
🗎 Site PagesEdit the OLD markdown sections (guides/news/compare). ⚠ Saves go straight to the live site — no draft stage. Be careful here.
🔑 SettingsLLM API keys, model choices, default image model, deploy hook

3 · Publish an article with AI (the normal flow)

1
AI Generator → pick a model from the dropdownOnly providers with keys appear. The best one is preselected.
2
Click 💡 Suggest TopicsWait ~15s. Five topic cards appear, based on Google Trends India + what's already on the site (no duplicates).
3
Click "Use This →" on the topic you likeEvery field fills itself (slug, EN + HI titles, category, angle, image scene). Edit anything you want, then click ＋ Queue Topic.
4
Generate the articleIn the Topics table: ⚡ Draft with AI (fast, ~30s, no automated checks) or ▶ Engine (full quality gates, ~10 min — preferred for facts/rules/prices). Each language row (EN, HI) is generated separately with ⚡.
5
Review the draftThe editor opens (or click "Review draft"). Read the whole article. Fix anything wrong — you are the editor. ⚠ With ⚡ drafts, double-check every number and rule.
6
Generate imagesRight column → 🎨 Generate Hero: the prompt is pre-filled from the article — edit it if you like, pick an image model, click Generate (~20s). Optionally add body images with "🖼 Insert AI image at cursor" under the text box. Check: the scooter must be a seated step-through model (never a standing kick-scooter) and carry no brand logos.
7
🚀 Save & PublishConfirms, marks it published, and triggers the website rebuild. The article is live at /blog/<slug> in ~1–2 minutes. (Hindi version appears at /hi/blog/<slug> once you publish the HI article too.)

5 · When something goes wrong

Message you seeWhat it means / what to do
"…NO quota for this model (free tier)"That provider account has no paid credit for this model. Pick a different model from the dropdown, or enable billing on the provider
"rate limit reached — wait ~30s"Too many requests too fast. Just wait and click again
"API key was rejected"The key is wrong or was revoked — paste a fresh one in Settings
"out of credits"Top up the account on the provider's billing page
"model not found"The model name in Settings has a typo — fix it there
Article published but not on the siteWait 2 min. Still missing → check Settings → Deploy Hook URL is filled in; then ask the site owner to check Vercel deployments
Golden rules for operators: ① Nothing goes live until YOU click Publish — take your time reviewing. ② ⚡ AI drafts are unverified: check every number, price and rule yourself. ③ Hero images: seated step-through scooter only, no brand logos. ④ Site Pages edits skip the draft stage — treat that screen as live surgery.
