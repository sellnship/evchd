# evchandigarh.in

Informational EV-mobility site for the Tricity region (Chandigarh / Mohali /
Panchkula). Static site built with [Astro](https://astro.build), deployed on
Vercel, built to be Google-Discover-ready.

> **Phase 0 — foundation skeleton.** This is the deployable skeleton only:
> Astro + TypeScript, sitemap, `robots.txt`, and a Discover/SEO `BaseLayout`.
> The content engine, calculators, data layer and design system come in later
> phases.

## Develop

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # static output → dist/
npm run preview  # preview the production build locally
```

## Deploy

Connect the repo to Vercel. Vercel auto-detects the **Astro** framework preset
(build command `astro build`, output directory `dist/`). No adapter is needed
for the static build.

## SEO / Discover baseline

`src/layouts/BaseLayout.astro` provides, on every page:

- a zoomable viewport (never `user-scalable=0`)
- `robots: max-image-preview:large, index, follow` (Discover large-image card)
- a canonical URL from the page path + `https://evchandigarh.in`
- Open Graph + Twitter `summary_large_image` (hero images are 1200×675)
- an RSS alternate link (`/rss.xml`, feed added in a later phase)
- `Article` JSON-LD when a page passes `type="article"` with a publish date

The sitemap is generated by [`@astrojs/sitemap`](https://docs.astro.build/en/guides/integrations-guide/sitemap/)
at `/sitemap-index.xml` and is referenced from `public/robots.txt`.
